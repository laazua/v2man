## 1. 快速开始

```
注册账号 → 充值 → 购买套餐 → 复制订阅链接 → 导入客户端 → 开始使用
```

## 2. 注册与登录

### 注册

1. 打开系统首页，点击 **「注册」**
2. 填写 **用户名**、**邮箱**、**密码**
3. 如有邀请码可填写（选填），享受邀请返利
4. 点击 **「注册」** 完成，自动登录

### 登录

1. 输入用户名和密码
2. 点击 **「登录」**
3. 系统自动跳转到仪表盘

---

## 3. 仪表盘

登录后首页为仪表盘，展示关键信息：

| 信息项 | 说明 |
|--------|------|
| **当前套餐** | 已购买的套餐名称，若无则为空 |
| **已用流量** | `已使用 / 总量`，附带进度条和百分比 |
| **到期时间** | 套餐到期日期 |
| **账户余额** | 钱包余额（单位：元） |
| **订阅 Token** | 订阅链接的唯一标识 |

## 4. 充值

充值入口：左侧导航栏 → **「充值」**

系统支持 **两种充值模式**，由管理员配置：

### 手动模式（人工审核）

```
步骤1：使用支付宝扫码付款（显示收款码）
步骤2：输入支付的金额，点击「提交充值」
步骤3：等待管理员确认到账
步骤4：余额自动增加
```

### 自动模式（支付宝当面付）

```
步骤1：输入充值金额，点击「去支付」
步骤2：屏幕上显示动态付款二维码
步骤3：打开支付宝扫码支付
步骤4：支付成功后系统自动到账
```

查看充值记录：充值页面显示历史支付订单及状态。

## 5. 购买套餐

入口：左侧导航栏 → **「套餐列表」**

1. 查看所有可用套餐（名称、价格、流量、时长）
2. 点击套餐卡片上的 **「购买」** 按钮
3. 系统自动从余额扣除对应金额
4. 购买成功后，套餐立即生效：
   - 流量配额更新
   - 到期时间更新
   - 节点配置同步到服务器

> **注意**：余额不足时会提示充值。购买新套餐后，剩余流量会被替换为新套餐的流量额度。

## 6. 使用订阅

入口：左侧导航栏 → **「订阅信息」**

### 获取订阅链接

页面显示三种订阅格式的链接，点击 **「复制」** 即可：

| 格式 | 适用客户端 |
|------|-----------|
| **V2Ray (Base64)** | V2RayN / V2Box / Shadowrocket / 小火箭 |
| **Clash Meta** | Clash Meta / Clash Verge / Stash / 克拉修行 |
| **Sing-box** | Sing-box / SFI / 冰晶 |

### 导入客户端

以 V2RayN 为例：

1. 打开 V2RayN
2. 点击 **「服务器」→「从剪贴板导入批量链接」**
3. 或复制订阅链接后，在 **「订阅设置」** 中添加订阅地址
4. 点击 **「更新订阅」**，节点自动加载

> 订阅链接包含您的身份信息和所有可用节点。**请勿泄露给他人**。

### 重置订阅

如怀疑订阅泄露，可联系管理员重置 UUID，重置后原有订阅链接立即失效。

## 7. 查看流量

入口：左侧导航栏 → **「仪表盘」**

- **概览**：仪表盘显示已用流量 / 总流量及进度条
- **明细**：`/api/traffic/stats/` 接口返回按日汇总的流量明细
- **提醒**：流量接近上限时，仪表盘进度条会变色提示

流量采集机制：系统每 5 分钟从节点服务器拉取一次流量数据，更新可能有数分钟延迟。

## 8. 邀请好友

入口：左侧导航栏 → **「邀请好友」**

### 邀请机制

1. 点击 **「生成邀请码」** 创建新邀请码
2. 将邀请码分享给好友
3. 好友注册时填写您的邀请码
4. 好友每次充值成功，您可获得一定比例的返利

### 查看收益

- **邀请记录**：查看所有通过您邀请注册的好友
- **收益统计**：累计获得的总返利金额
- **提现**：达到最低提现金额后，可申请将返利提现到账户余额

### 返利配置

返利比例和最低提现金额由管理员在后台配置（默认返利 20%）。

## 9. 密码重置

### 请求重置

1. 在登录页点击 **「忘记密码？」**
2. 输入注册时填写的邮箱
3. 点击 **「发送重置链接」**
4. 检查邮箱，点击重置链接

### 确认重置

1. 从邮件中的链接打开重置页面
2. 输入新密码（至少 6 位）
3. 确认提交，密码重置成功
4. 返回登录页使用新密码登录

> 如未收到邮件，请检查垃圾邮件箱，或联系管理员确认邮箱配置是否正常。

## 10. 联系客服

入口：左侧导航栏 → **「联系客服」**

1. 输入 **主题** 和 **留言内容**
2. 点击 **「发送」**
3. 管理员回复后，您会在 **「通知」** 中收到提醒
4. 可在同一页面查看完整的对话记录

## 11. 常见问题

### Q: 充值后多久到账？

手动模式需要管理员确认，通常在工作时间内数小时内到账。自动模式支付成功后即时到账。

### Q: 流量多久更新一次？

系统每 5 分钟从节点服务器采集一次流量数据，最长可能延迟 5 分钟。

### Q: 套餐到期后会怎样？

到期后用户会被自动停用：流量清零、套餐清空、无法连接节点。续费购买新套餐即可恢复。

### Q: 订阅链接失效怎么办？

联系管理员重置订阅，获取新的订阅链接后重新导入客户端。

### Q: 可以在多个设备上使用吗？

可以。订阅链接支持多设备同时使用，所有设备的流量合并计算。

### Q: 购买套餐后流量没用完能累积到下月吗？

不可以。购买新套餐后，流量配额替换为新的额度，不会累积。

### Q: 如何查看通知？

点击左侧导航栏 **「通知」** 查看所有系统通知和客服回复。

### Q: 忘记用户名怎么办？

联系管理员，提供注册邮箱查询用户名。
